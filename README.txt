Notif Tiles v0.1

BUILD (pick one)
A) Android Studio on a PC: File > Open this folder, wait for sync, Build > Build APK(s).
B) GitHub Actions (no PC needed beyond git): push this folder to a new GitHub repo,
   open the Actions tab > Build APK > Run workflow, then download the
   notiftiles-apk artifact (app-debug.apk).

INSTALL AND SET UP
1. Install the APK. Open "Notif Tiles setup".
2. If notification access is greyed out: Settings > Apps > Notif Tiles > three-dot
   menu > Allow restricted settings. Then grant notification access.
3. Set battery to unrestricted for Notif Tiles.
4. Tap "Turn on my usual apps", adjust the switches.
5. On Nova, add the "Notif Tiles" icon (not "setup") to your home screen.
